# Domain Docs

## Layout

Single-context repository:
- `GLOSSARY.md` at repository root
- System-wide ADRs in `docs/adr/` numbered sequentially (`0001-<slug>.md`)

## Rules

- Always consult `GLOSSARY.md` before writing code or specs
- Canonical vocabulary must be adhered to (e.g. Warp instead of Pull, Stellar Jade instead of Gem)
- Offer ADRs sparingly: only when hard to reverse, surprising without context, and result of a real trade-off
