# Issue Tracker: Local Markdown

Issues live as markdown files under `.scratch/hsr-sim/issues/` in this repository.

## Conventions

- Each issue is a separate file: `.scratch/hsr-sim/issues/<NN>-<slug>.md`
- Sequential numbering starting from `01`
- Dependency edges tracked in the "Blocked by" field
- Status tracked as `ready-for-agent`, `in-progress`, `done`, etc.
